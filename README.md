# Dual subtitles

Userscript для онлайн-кінотеатрів: показує **два рядки субтитрів одночасно** — повні англійські і переклад (українська, далі російська — що є).
Перевірено у Firefox і Chrome з Violentmonkey. З Tampermonkey має працювати так само, але не перевірялось.

![](https://img.shields.io/badge/version-2.4.1-blue) ![](https://img.shields.io/badge/license-MIT-green)

## Встановлення

1. Поставте менеджер скриптів: [Violentmonkey](https://violentmonkey.github.io/) (рекомендовано) або Tampermonkey.
2. Відкрийте [dual-subtitles.user.js](https://raw.githubusercontent.com/DominusLeo/dual-subtitles/main/dual-subtitles.user.js) і натисніть **Install**.
3. Увімкніть фільм із субтитрами. Скрипт сам вибере доріжки.

Оновлення підтягуються автоматично з цього репозиторію.

## Що робить

- Шукає в плеєрі доріжки субтитрів: нативні `<track>` у HTML5-плеєрах і списки субтитрів Playerjs (rezka).
- Знизу — **повна** англійська доріжка. Доріжки SDH (з описом звуків) і форсовані (лише написи в кадрі) пропускає.
- Згори — перша мова зі списку `topLangs` (`uk`, потім `ru`), для якої є повна доріжка.
- Малює обидва рядки сам поверх відео, тому працює однаково у Firefox і Chrome і в повноекранному режимі.
- Переживає рекламу перед фільмом: коли плеєр міняє джерело відео, скрипт відновлює доріжки.
- Працює в iframe-плеєрах балансерів, зокрема в тих, які сайт пише в iframe без `src`.

## Клавіші

Усі — з `Alt`. Вибір зберігається в браузері окремо для кожного домену плеєра.

| Клавіша | Дія |
|---|---|
| `Alt+S` | вимкнути / увімкнути |
| `Alt+L` | розкладка: переклад згори + англійська знизу ↔ обидва рядки знизу |
| `Alt+=` / `Alt+-` | розмір шрифту ±10 % (40–250 %) |
| `Alt+↑` / `Alt+↓` | підняти / опустити нижній блок на 1 % висоти відео |
| `Alt+0` | скинути до налаштувань за замовчуванням |

Після натискання вгорі кадру на 1,5 с з'являється підказка з поточними значеннями.

У розкладці «обидва знизу» кожен рядок іде в одну лінію. Задовгий рядок зменшується до 60 % розміру, далі переноситься.

## Налаштування

Значення за замовчуванням — в об'єкті `CFG` на початку скрипта: мови, розміри й відступи, пороги розпізнавання повних/форсованих/SDH доріжок, клавіші.
Правка `CFG` у редакторі менеджера скриптів зникне при наступному оновленні — для щоденного використання достатньо клавіш.

## Тестовий стенд

`firefox-harness/` — автоматичні прогони у справжніх Firefox і Chrome через [puppeteer-core](https://pptr.dev/) (Windows-шляхи браузерів — на початку `run.mjs`).

```bash
cd firefox-harness
npm ci
node run.mjs <url> steps-embed.json out/my-run            # Firefox, скрипт підставляється в кожен фрейм
BROWSER=chrome node run.mjs <url> steps-embed.json out/cr  # Chrome
bash regress.sh                                           # повна регресія: 6 прогонів
```

- Кроки (`steps-*.json`): `wait`, `click`, `play`, `seek`, `seekCue`, `key` (`"Alt+KeyL"`), `eval`, `probe`, `shot`.
- Результат — `out/<run>/report.json` (доріжки, текст і геометрія рядків, журнал) і скріншоти; зведення — `summarize.py`.
- `EXT=1` — Firefox з Adblock Plus і Violentmonkey, скрипт ставить сам Violentmonkey з `http://127.0.0.1:8766/`.
  Файли `ext/adblock_plus-4.46.0.xpi` і `ext/violentmonkey-2.49.0.xpi` завантажте з addons.mozilla.org; у репозиторії їх немає.
